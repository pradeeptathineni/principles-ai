# Review Content Workflow

Review corpus changes independently from generation when practical.

## Review order

1. **Scope** — Does this content belong in this file?
2. **Principle quality** — Is the idea important, durable, distinct, and actionable?
3. **Source quality** — Are stronger or more direct sources available?
4. **Entailment** — Does each citation support the exact claim?
5. **Calibration** — Is wording stronger than evidence?
6. **Nuance** — Are meaningful conditions, disagreements, or exceptions missing?
7. **Practices** — Do they operationalize the principle rather than introduce unrelated advice?
8. **Goals** — Are they developmental outcomes rather than disguised practices?
9. **Readability** — Is the file useful to a human learner?
10. **Machine structure** — Does it comply with the schema?
11. **Duplication** — Does it repeat existing content without contextual value?
12. **Change impact** — Does the evidence justify the semantic impact?

Reject polished prose that lacks evidence.
